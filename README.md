# Noon Scraper

A tool that scrapes and serves product data from [noon.com](https://www.noon.com).

## Structure

```
Noon Scraper/
├── Backend/     # ASP.NET Core Web API + PostgreSQL (EF Core)
└── Frontend/    # Vite + React
```

See [`Backend/README.md`](Backend/README.md) and [`Frontend/README.md`](Frontend/README.md) for setup instructions.
